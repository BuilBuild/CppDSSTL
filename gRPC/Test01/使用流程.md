### **1. 安装依赖**
- **安装 Protocol Buffers 编译器 (protoc)**  
  用于将 `.proto` 文件编译为代码。  
  - **Ubuntu**: `sudo apt install protobuf-compiler`  
  - **MacOS**: `brew install protobuf`  

- **安装 gRPC 库**  
  - **C++**:  
    ```bash
    # 使用 vcpkg 安装（推荐）
    vcpkg install grpc protobuf
    ```
  - **其他语言**（如 Go、Python）:  
    通过包管理工具安装对应语言的 gRPC 库（如 `pip install grpcio`）。

---

### **2. 定义服务接口（.proto 文件）**
使用 Protocol Buffers 语法定义服务和方法，并指定请求/响应消息格式。  
示例 `example.proto`：
```protobuf
syntax = "proto3";

package example;

// 定义服务
service DataService {
  // 简单 RPC
  rpc GetData (DataRequest) returns (DataResponse) {}
  
  // 服务端流式 RPC
  rpc StreamData (DataRequest) returns (stream DataResponse) {}
}

// 请求消息
message DataRequest {
  string query = 1;
}

// 响应消息
message DataResponse {
  repeated string results = 1;
}
```

---

### **3. 生成代码**
使用 `protoc` 工具生成服务端和客户端代码：  
```bash
protoc -I=. --grpc_out=. --cpp_out=. \
--plugin=protoc-gen-grpc=`which grpc_cpp_plugin` \
example.proto
```
- **生成文件**：  
  - `example.pb.{h,cc}`: 消息序列化代码。  
  - `example.grpc.pb.{h,cc}`: gRPC 服务端和客户端基类代码。

---

### **4. 实现服务端**
#### **同步服务端**
1. **继承生成的 Service 基类**，实现 RPC 方法：  
   ```cpp
   class DataServiceImpl final : public DataService::Service {
     grpc::Status GetData(
         grpc::ServerContext* context,
         const DataRequest* request,
         DataResponse* response) override {
       // 填充 response
       response->add_results("Result1");
       return grpc::Status::OK;
     }
   };
   ```

2. **启动服务端**：  
   ```cpp
   grpc::ServerBuilder builder;
   builder.AddListeningPort("0.0.0.0:50051", grpc::InsecureServerCredentials());
   DataServiceImpl service;
   builder.RegisterService(&service);
   std::unique_ptr<grpc::Server> server(builder.BuildAndStart());
   server->Wait(); // 阻塞等待请求
   ```

#### **异步服务端（高性能场景）**
- 使用 `CompletionQueue` 处理并发请求，需手动管理生命周期。

---

### **5. 实现客户端**
#### **同步客户端**
```cpp
auto channel = grpc::CreateChannel("localhost:50051", grpc::InsecureChannelCredentials());
std::unique_ptr<DataService::Stub> stub = DataService::NewStub(channel);

DataRequest request;
request.set_query("test");

DataResponse response;
grpc::ClientContext context;
grpc::Status status = stub->GetData(&context, request, &response);

if (status.ok()) {
  std::cout << "Response: " << response.results(0) << std::endl;
}
```

#### **流式客户端**
```cpp
// 服务端流式调用
grpc::ClientContext context;
DataRequest request;
request.set_query("stream");
std::unique_ptr<grpc::ClientReader<DataResponse>> reader = stub->StreamData(&context, request);

DataResponse response;
while (reader->Read(&response)) {
  std::cout << "Received: " << response.results(0) << std::endl;
}
```

### **6. 编译与运行**
使用 **CMake** 管理项目（示例 `CMakeLists.txt`）：
```cmake
cmake_minimum_required(VERSION 3.10)
project(grpc_example)

find_package(Protobuf REQUIRED)
find_package(gRPC REQUIRED)

# 生成 proto 文件的代码
protobuf_generate_cpp(PROTO_SRCS PROTO_HDRS example.proto)
grpc_generate_cpp(GRPC_SRCS GRPC_HDRS example.proto)

add_executable(server server.cpp ${PROTO_SRCS} ${GRPC_SRCS})
target_link_libraries(server PRIVATE grpc++ protobuf)

add_executable(client client.cpp ${PROTO_SRCS} ${GRPC_SRCS})
target_link_libraries(client PRIVATE grpc++ protobuf)
```

编译命令：
```bash
mkdir build && cd build
cmake .. && make
./server & ./client
```

### **7. 高级功能**
1. **认证与加密**  
   - 使用 SSL/TLS 证书：  
     ```cpp
     grpc::SslServerCredentialsOptions ssl_opts;
     ssl_opts.pem_root_certs = "path/to/cert.pem";
     builder.AddListeningPort("0.0.0.0:50051", grpc::SslServerCredentials(ssl_opts));
     ```

2. **拦截器（Middleware）**  
   继承 `grpc::experimental::Interceptor`，实现日志、鉴权等统一逻辑。

3. **健康检查**  
   使用 `grpc::health::v1::Health` 服务，监控服务状态。

---

### **8. 常见问题**
- **依赖冲突**：确保 protobuf 和 gRPC 版本兼容。  
- **流式通信**：需正确处理 `Read()` 和 `WritesDone()` 的生命周期。  
- **性能优化**：异步 API 适合高并发场景，但代码复杂度较高。

---

通过以上流程，您可以快速创建 gRPC 服务端和客户端，并根据需求扩展功能。
